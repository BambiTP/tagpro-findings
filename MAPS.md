# Maps: every number in one table

One row per map with at least 100 ranked replays. Terms are explained in [GLOSSARY.md](GLOSSARY.md);
how each number was checked is in [FINDINGS.md](FINDINGS.md).

| Column | What it is |
|---|---|
| Ranked replays | Ranked capture-the-flag games with full position data, March 2025 to October 2026 |
| Caps / grabs per game | Both teams together. Grabs include quick returns (flaccids), so grabs far outnumber caps |
| Powerup fights per game | A powerup respawning with at least 3 players within 5 tiles |
| Break-off grabs per game | A grab within 5 s of a powerup fight by someone not in the fight |
| Regrab chains per game | A carrier returned, then the same flag regrabbed by their team within 2 s |
| Bombs set off / bomb gifts / free past 4s | See the bomb gift entry in the glossary |
| Caps after a bomb gift | Share of caps within 10 s of a bomb gift |
| Skill effect, ranked / public | How strongly our rating gap predicts the winner (2024-2026, log odds per 100 points). Higher = more skill-decided. These per-map values are noisy; see findings section 4b |
| Clean games | No uneven teams for 30 s+ and no player idle 10%+ of the game |
